## 3. Subsystem Breakdown

### A. Backend Configuration (`backend/src/shared/config.js`)
- **Required for Dev**: `PORT`, `HOST`, `DATABASE_URL`, `REDIS_URL`, `MQTT_BROKER_URL`, `JWT_SECRET`, `SESSION_SECRET`.
- **Required for Production**: Strict TLS (`MQTT_TLS_BROKER_URL=mqtts://...`), high-entropy `JWT_SECRET` (min 32 chars), production `DATABASE_URL` (non-localhost).
- **Startup Enforcement**: Handled by `validateConfig(config)` on bootstrap.

### B. Flutter Configuration (`smart_home_application_v1/lib/core/config/app_config.dart`)
- **Supported Mechanism**: `--dart-define=BACKEND_BASE_URL=http://<YOUR_LAN_IP>:3000` (or `--dart-define-from-file=.env.json`).
- **Precedence**:
  1. Compile-time `--dart-define=BACKEND_BASE_URL=...`
  2. Injected testing parameters
  3. Dev LAN fallback (`http://192.168.1.8:3000` on Android)
  4. In Production (`APP_ENV=production`), throws fast `StateError` if unconfigured.

### C. Physical Hardware & Factory Partition (`firmware/`)
- **Identity Source**: Partition `fact_v2` at flash offset `0x12000` (16 KB).
- **Runtime Discovery**: Mobile app discovers device ID and serial dynamically by reading BLE GATT Characteristic `00006105-0000-1000-8000-00805f9b34fb`.
- **Wi-Fi Persistence**: Stored in partition `nvs` under namespace `eh_wifi` (keys `ssid`, `pass`).

### D. Commissioning & QR Flow
- **Data Path**:
  `factory_provisioner.py` -> Generates QR payload `EH1:<uuid>:<variant>:<secret_hex>:<setup_code>` -> User scans QR in Mobile App -> 256-bit secret loaded into ephemeral memory -> AES-256-GCM transcript handshake performed -> Wi-Fi credentials sent encrypted -> Device marks secret consumed.

## 6. Values NOT to Provide Manually

To prevent architectural regressions, do **NOT** attempt to provide or hardcode:
- `homeId` / `roomId` (Generated dynamically in database at runtime).
- `deviceId` / `serialNumber` (Flashed into ESP32 `fact_v2` and read over BLE).
- `commissioningSecret` (Embedded in the factory QR code and read via phone camera).
- `BL0942 calibration registers` (Defined in product hardware profile).
